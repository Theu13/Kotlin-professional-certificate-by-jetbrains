## 📋 Sobre a Certificação

O **Kotlin Professional Certificate by JetBrains** é uma trilha de aprendizado estruturada disponível no LinkedIn Learning, cobrindo o desenvolvimento moderno com Kotlin.

- 🕐 **Duração total:** ~11 horas
- 🎓 **Plataforma:** LinkedIn Learning
- 🛠️ **IDE utilizada:** IntelliJ IDEA
- 🏆 **Certificado:** Emitido pela JetBrains, compartilhável no LinkedIn

- Consolidar o domínio da linguagem Kotlin com foco em **backend** e **multiplatform**
